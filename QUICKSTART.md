# LinksFácil PWA

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Deploy na Vercel

1. Conecte o repositório GitHub à Vercel
2. O deploy é automático a cada push em `main`
3. Acesse o URL fornecido pela Vercel

## 📝 Notas

- O aplicativo é 100% funcional como PWA
- Todos os dados são armazenados em localStorage
- Funciona completamente offline
- Pode ser instalado como app nativo
